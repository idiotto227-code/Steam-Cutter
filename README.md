# Steam Cutter 5.0.1

Портативная студия для подготовки витрин Steam на Windows 10/11 x64. Откройте **Steam Cutter.exe** и перетащите изображение в окно. Программа подгонит ширину, сохранит пропорции, нарежет панели и покажет результат.

| Витрина | Выходные файлы |
| --- | --- |
| Моя мастерская | Пять полос по 150 px, слева направо |
| Иллюстрации | Центральная часть 506 px и боковая часть 100 px |

### Импорт и сохранение

- Поддерживаются GIF, PNG, APNG, JPEG и WebP. Обычные изображения сохраняются в PNG, анимация — в GIF.
- Можно выбрать несколько файлов, перетащить их в окно, вставить прямую ссылку или ссылку на открытую HTML-страницу. Для страницы программа пробует изображение предпросмотра и обычные теги изображений. Ссылки на страницы, где изображение появляется только после входа или выполнения сценариев сайта, могут потребовать прямую ссылку на файл.
- Во вкладке «Входящие» откройте папку, положите туда файлы и нажмите «Обработать папку». Повторный запуск создаёт новый комплект. Оригиналы сохраняются.
- По умолчанию результаты попадают в «Документы/SteamCutter/Exports». Папку можно изменить. У каждого комплекта своя папка и отдельная кнопка открытия.
- При смене макета после обработки приложение автоматически нарежет последнее изображение под выбранный формат.
- Цель оптимизации — до 5 000 000 байт на часть. Для тяжёлых анимаций программа уменьшает палитру, затем объединяет интервалы кадров, сохраняя общую длительность. Карточка результата показывает число сохранённых и исходных кадров. Если комплект всё ещё слишком большой, программа сообщит об этом.
- Ограничения на вход: 32 МиБ, 48 Мп на кадр, до 1600 кадров, до 2 млрд пикселей по всем кадрам. Высота результата — до 4096 px. GIF поддерживает однобитную прозрачность и точность времени 10 мс.
- Интерфейс на русском, украинском и английском. Для окна приложения нужен Microsoft Edge WebView2 Runtime и .NET Framework 4.8. При отсутствии WebView2 приложение предложит официальную страницу установки.

### Публикация

По умолчанию Steam открывается автоматически после нарезки. При обработке папки или группы файлов откроется первый готовый комплект. Флажок под источником отключает автоматическое открытие. Любой комплект можно открыть кнопкой «Открыть в Steam». Встроенное окно открывает официальный сайт Steam. Вход и Steam Guard выполняются на стороне Steam. Выберите часть по имени, перетащите файл на поле загрузки или скопируйте его путь в диалог выбора файла. Проверьте видимость, подтвердите свои права и отправьте форму. Повторите для следующей части. Затем разместите опубликованные материалы в редакторе профиля Steam.

Форма «Иллюстрации» публикует материал в галерее иллюстраций. Для «Моей мастерской» приложение готовит пять файлов и открывает каталог мастерских. Публикация именно как Workshop Item зависит от инструментов выбранной игры. Обычная загрузка иллюстрации не создаёт предмет мастерской. Если Steam требует обычный браузер, откройте текущую официальную страницу кнопкой «В браузере».

[Иллюстрации Steam](https://help.steampowered.com/ru/faqs/view/53FC-FF49-3C78-D019) · [Загрузка материалов Steam Workshop](https://partner.steamgames.com/doc/features/workshop/implementation)

### Сборка и проверка

Из корня репозитория выполните `python tools/package.py` с .NET SDK 8 и Python 3. Результат появится в каталоге `build`. Для тестов редактора нужны Python, Pillow, Playwright и Chromium. Команда — `python tests/test_editor.py`. Переменная `CHROMIUM` позволяет указать исполняемый файл браузера. На Windows `python tests/windows_smoke.py "build/Steam Cutter.exe"` проверяет запуск, сохранение двух макетов и открытие Steam без публикации.
